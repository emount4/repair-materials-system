# Проверка ПР5 по методичке

Методичка: «ПР5 Django, HTTP и основы веб-разработки», разделы 5–7.
Предметная область примера Roomly адаптирована к учету материалов ИП:
`Room` соответствует `Material`, `Booking` соответствует `Operation`.
Рабочая версия ПР5 находится в `main`; ПР6 показывается в отдельной ветке.

## Проверка общей страницы 404

1. В `inventory_web/settings.py` временно задать `DEBUG = False`.
2. Запустить `python manage.py runserver` и открыть `/nonexistent/`.
3. Показать оформленную страницу 404 с навигацией и ссылкой на главную.
4. Открыть `/materials/999/`: сообщение «Материал не найден», статус 404.
5. Вернуть `DEBUG = True`, как предусмотрено разделом 5.4.7.

`handler404` объявлен только в корневом URLconf. При `DEBUG=False` он
обрабатывает неизвестный маршрут и исключение `Http404` из view. Готовый
`HttpResponse(status=404)` из представления возвращается напрямую.
