## Индивидуальный проект

**Название:** Система учета материалов для ремонта.

**Репозиторий:** https://github.com/emount4/repair-materials-system

Программа из ПР1 расширена до консольного приложения с меню. Добавлены
хранение нескольких материалов, поиск, сортировка, отбор по категории,
поступления, расходы, отмена операций и статистика запасов. Сохранены
расчет стоимости, проверка наличия и расчет остатка из ПР1.

Код разделен на модули: `main.py` — интерфейс; `materials.py` — материалы
и расчеты; `operations.py` — операции; `storage.py` — файлы; `utils.py` —
проверка ввода. Данные представлены списками словарей и хранятся
в `data/inventory.json`. В файл записываются материалы и история операций.
Использованы циклы, множества, генератор с `yield`, сортировка с `lambda`,
контекстные менеджеры и обработка исключений. Основные функции имеют
аннотации типов и документирующие строки.

Некорректный ввод запрашивается повторно. Программа запрещает списание
сверх остатка и повторную отмену. Поврежденный файл данных не перезаписывается;
ошибка сохранения не применяет изменение в памяти.
